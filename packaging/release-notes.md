CVRTR: локальный конвертер WAV, MP3, FLAC, OGG и M4A с переносом основных тегов и обложки.

Файлы:
- `windows-x86_64.zip`: распаковать целиком и запустить `cvrtr_gui.exe`.
- `ubuntu24.04-amd64.deb`: Ubuntu 24.04 / Linux Mint 22 x86_64; установить через `sudo apt install ./имя-файла.deb`.
- `source.tar.gz`: исходники CVRTR для этой версии.
- `SHA256SUMS.txt`: контрольные суммы файлов.

Лицензия CVRTR: GNU GPL v3 only. Сведения о зависимостях находятся в THIRD_PARTY.md и manifests внутри пакетов.

ПЕРЕД ПУБЛИКАЦИЕЙ ЧЕРНОВИКА:
1. Проверить ZIP на Windows без MSYS2 и DEB на чистой Ubuntu 24.04.
2. Приложить соответствующие исходники распространяемых DLL (включая точные версии и патчи MSYS2) и исходники встроенных GLFW/ImGui/portable-file-dialogs либо дать устойчивые ссылки на эти точные исходники. Сверить версии с manifest.
3. Добавить ссылки на эти исходники в описание релиза, обновить SHA256SUMS.txt при добавлении архивов, заменить этот список итоговыми заметками и только затем нажать Publish release.
